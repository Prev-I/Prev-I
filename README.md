## Current focus: Agentic Software Engineering

My current engineering focus is the responsible adoption of AI coding agents in real-world software delivery.

I am researching and building practices that allow engineering teams to benefit from AI-assisted development without sacrificing traceability, architectural intent, reproducibility, or human accountability.

This work currently includes:

* portable workflows across OpenCode, Codex, and Claude Code;
* shared engineering instructions and cross-harness conventions;
* deterministic multi-model routing and role separation;
* Spec-Driven Development for AI-assisted delivery;
* governed agent execution and workflow orchestration;
* reusable development environments, tools, patterns, and reference implementations.
